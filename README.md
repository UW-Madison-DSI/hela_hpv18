# HeLa HPV18 sequences

These are the scripts and data used to quantify HPV18 sequences in bulk HeLa MBR samples.

## HeLa samples
HeLa MBR samples came from GEO Series GSE305263.

## HPV sequences
HPV18 gene sequences were manually aggregated from [Genbank](https://www.ncbi.nlm.nih.gov/nuccore/NC_001357) into `hpv18.fa.gz`.
